# Generated Item Data

This directory contains master data generated from `public/data/item.txt`.

## Files

- `items.json`: The complete item database (250 items, 750 variants).

## Format

Each item in `items.json` follows this structure:

```json
{
  "id": "IT_ARM_ME_01",
  "category": "ARM",
  "principle": "ME",
  "index": "01",
  "image": "items/IT_ARM_ME_01.png",
  "variants": {
    "normal": {
      "description": "...",
      "effect": "..."
    },
    "success": { ... },
    "great_success": { ... }
  }
}
```

## Generation

Generated by `tools/convert_items.js`.
Do not edit `items.json` directly. Update `public/data/item.txt` and re-run the conversion tool instead.
