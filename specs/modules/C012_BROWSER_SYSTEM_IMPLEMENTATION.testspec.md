# Test Specification: C012_BROWSER_SYSTEM_IMPLEMENTATION

## Overview
ブラウザ実装層の統合動作と、永続化・演出・表示制御の正当性を検証する。

## Test Environment
- **Runtime:** Browser (Chrome/Firefox/Safari)
- **Framework:** Playwright (Smoke Test) / Manual verification
- **Target:** `public/index.html` (bundled via `tools/build-browser-bundle.cjs`)

## Test Cases

### 1. 画面遷移と基本サイクル
- **T1.1:** タイトル画面からオープニング、ヒロイン選択へと遷移できるか。
- **T1.2:** 営業（クイズ）フェーズで10問回答後、自動的にリザルト画面へ遷移するか。
- **T1.3:** エンディング後にタイトル画面へ戻り、状態が初期化されるか。

### 2. 永続化と再開 (Save & Resume)
- **T2.1:** ヒロイン選択後にリロードし、選択画面をスキップしてVNパートから開始されるか。
- **T2.2:** クイズ中にリロードし、そのターンの開始時点（または中断した問題）から再開できるか。
- **T2.3:** エンディング到達フラグがリロード後も保持され、タイトル画面の「続きから」や解放要素に反映されるか。

### 3. 演出エンジン (Audio & Effects)
- **T3.1:** 画面遷移に伴い、対応するBGMがフェードしながら切り替わるか。
- **T3.2:** クイズの回答判定（正解・不正解）に合わせて、適切な効果音が遅延なく再生されるか。
- **T3.3:** ターン切り替え時の暗転・演出が、CSS変数を介して意図した通りに実行されるか。

### 4. 表示制御 (Character Visuals)
- **T4.1:** キャラクタごとに異なるスケール設定が、DOMの `transform` や CSS変数として正しく出力されているか。
- **T4.2:** 話者アイコン（Face）の切り出し位置が、定義されたプロファイルと一致しているか。
- **T4.3:** 立ち絵の表情変更時に、プロファイルが即座に再適用され、表示崩れが起きないか。

### 5. アセットプリロード
- **T5.1:** ヒロイン選択直後に、そのヒロイン専用のBGMや立ち絵のロードが開始されるか。
- **T5.2:** プリロード未完了状態で画面を表示した場合でも、クラッシュせずに代替表示が行われるか。

## Success Criteria
- [ ] すべてのクリティカルパス（タイトル→営業→エンディング）が、リロードを挟んでも完走可能である。
- [ ] 演出（音声・アニメーション）のラグが許容範囲内（0.1s以内）である。
- [ ] ブラウザの開発者ツールで、`localStorage` に意図した形式でデータが保存されていることが確認できる。
