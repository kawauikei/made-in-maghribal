# I001: Browser Playthrough Test Specification

## テスト概要
ブラウザ上でゲームがTITLEからENDINGまで正常に進行し、セッション状態が期待通りに遷移することを検証する。
現在は自動テスト環境がないため、手動テストチェックリストとして定義する。

## テスト環境
- ブラウザ: Chrome / Edge / Safari (モバイル対応含む)
- 実行方法: `public/index.html` をローカルサーバーまたは直接開く。

## テストケース

### T1: タイトルから開始
1. `public/index.html` を開く。
2. **期待結果**: TITLE画面が表示され、「Made in Maghribal」と「Click to Start」が表示されること。

### T2: ヒロイン選択
1. TITLE画面をクリックする。
2. **期待結果**: OPENING画面が表示されること。
3. OPENING画面をクリックする。
4. **期待結果**: HEROINE_SELECT画面が表示され、HAKIMA, MIRA, DARIYAの選択肢が出ること。
5. いずれかのヒロインカードをクリックする。
6. **期待結果**: MAIN_GAME (BEFORE_OPEN) フェーズに遷移すること。

### T3: 営業サイクル (QUIZ)
1. BEFORE_OPEN画面をクリックする。
2. **期待結果**: QUIZ画面に遷移し、問題文と2択の選択肢が表示されること。
3. 選択肢をクリックする。
4. **期待結果**:
   - 中央に判定（PERFECT等）が表示されること。
   - スコア（Gold/Sat）が更新されること。
   - 次の問題が表示されること。
5. 10問回答する。
6. **期待結果**: 自動的に TURN_RESULT 画面が表示されること。

### T4: ターン終了と次ターン遷移
1. TURN_RESULT 画面でスコアを確認し、「Next Phase」をクリックする。
2. **期待結果**: AFTER_CLOSE 画面に遷移すること。
3. AFTER_CLOSE 画面をクリックする。
4. **期待結果**:
   - Turn 1〜4の場合: 次ターンの BEFORE_OPEN へ戻ること（Turn番号がインクリメントされていること）。
   - Turn 5の場合: ENDING 画面に遷移すること。

### T5: エンディングとリスタート
1. Turn 5終了後に ENDING 画面が表示されることを確認する。
2. **期待結果**: エンディング判定（GOOD/NORMAL）と最終結果が表示されること。
3. 「Return to Title」をクリックする。
4. **期待結果**: TITLE画面に戻り、全てのスコアとTurn番号が初期化されていること。

## 異常系・境界条件
- **連打防止**: クイズ回答時や遷移時にクリックを連打しても、二重にフェーズが進んだりエラーが出たりしないこと。
- **レジューム**: 現在ランのオートセーブが存在する場合、タイトルの「つづきから」から中断中のフェーズを復元できること。クイズ中の保存では、保存済みの問題番号、現在問題、選択肢を復元できること。
