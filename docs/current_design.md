# Made in Maghribal Current Design

## 現在の目的
10ターン制の短編工房経営ADVを作る。
まずは「客の注文を読み、左右2択の商品から正しい品を渡す接客分類クイズ」をMVPとして作る。
AI生成は最初から全体に使わず、デートイベント・エンディングなど山場だけに使う。

## 現在作らないもの
- 補充システム
- ランダムイベント
- ヒロイン能力
- 幼馴染モード
- AI画像生成
- 図鑑
- セーブ/ロード
- 大量のイベント本文

## 最初に作るMVP
20問連続の2択接客クイズ。

仕様：
- 客の注文文を表示する。
- 左右に商品カードを2つ表示する。
- 正しい商品を選ぶ。
- 正解ならスコア加算。
- 不正解なら加算なし。
- 最初はタイマーなし。
- 最初は在庫・補充・ヒロイン補正なし。
- 問題種別は以下の4つ。
  - 色指定：青いもの
  - ジャンル指定：武器
  - 品目指定：短剣
  - 色＋品目指定：青い短剣

## 後で追加する予定
順番は以下。
1. 正解/不正解演出
2. スコア
3. 回答速度による品質判定
   - normal
   - success
   - great_success
4. 10回の営業工程
5. 営業結果報告
6. ヒロイン選択
7. ヒロインごとの補正
8. ED分岐
9. AI生成ED
10. AI画像生成

## ゲーム設計の原則
- UIは表示するだけ。
- game は判定・進行ルールだけを持つ。
- data は定義だけを持つ。
- gemini は生成処理だけを持つ。
- UIコンポーネントの中にスコア計算や正誤判定を書かない。
- ルール変更は game/ 配下で完結させる。
- 表示変更は ui/ 配下で完結させる。
- アイテムやヒロインの文言変更は data/ 配下で完結させる。

## ゲーム全体の予定構造
1. 三人から好きな相手を選んで進める。
2. 10ターン制。
3. 各ターンは、開店、接客、閉店、収支報告、夜イベントで構成する。
4. 4ターン目と7ターン目にイベントを入れる予定。
5. 累計スコアでエンディング分岐。
6. ベストエンディングでクリアすると幼馴染モードが解放される予定。

## アイテム分類方針
アイテムは以下の3軸で分類する。
- 色
- ジャンル
- 品目

難易度：
- 低：色指定
- 中：ジャンル指定
- 高：品目指定
- 最高：色＋品目指定

例：
- 青いもの
- 武器
- 短剣
- 青い短剣

## 生成AIの使い方
- 通常プレイ部分は固定実装でテンポ重視。
- AI生成はデートイベント、エンディング、ベストED後の特別演出などに限定する。
- APIキーがない、上限に達した、生成に失敗した場合でも非生成モードで遊べるようにする。
- 非生成モードを本体、生成モードを拡張演出として扱う。

## 会話劇の立ち絵演出方針 (話者フォーカス制)

スマホ等の小画面（390px幅）でも、誰が話しているかを視覚的に分かりやすくし、UIの窮屈さを解消するための演出方針。

### 基本原則
- **話者フォーカス**: 話しているキャラを強調し、話していないキャラを背景化する。
- **VNBox優先**: VNBoxは常に最前面（z-index: 6以上）を維持するが、キャラの顔を隠さない配置を心がける。

### 演出パラメータ
- **話しているキャラ (フォーカス中)**:
  - 拡大表示 (height: 62〜70%)
  - 不透明度: 0.95〜1.0
  - z-index: 3 (非話者より前面)
  - 明るさ: 通常
- **話していないキャラ (背景化)**:
  - 縮小表示 (height: 50〜58%)
  - 不透明度: 0.35〜0.55
  - z-index: 2 (話者より背面)
  - 画面端に寄せる
  - 少し暗めに表示

### 適用範囲
- **PROLOGUE**: ナーディルが物語案内役として主役表示（右下）。
- **INTRO**: 客であるヒロインを主役表示（右下、opacity 0.9〜1）。ナーディルは立ち絵非表示または極めて控えめ。
- **EVENT (将来)**: 親愛イベント等での二人会話劇において、話者フォーカス制を導入予定。スチルがある場合はスチルを最優先し、立ち絵は非表示とする。

## ビルド運用
- src/ を編集する。
- build.bat を実行する。
- public/main.js と main.canvas.jsx が生成される。
- main.canvas.jsx は Gemini Canvas に直接貼って確認する。
- public/main.js は GitHub Pages 経由で loader.js から読み込まれる。
- public/main.js と main.canvas.jsx は直接編集禁止。
