# M10-2B Scenario Rewrite Draft v1

目的：まずゲームとして流せる短い本文を入れるためのたたき台。  
方針：説明を長くせず、1ページ60〜80字前後。通常ルートは「現在から育つ縁」、long_historyは「過去から続く縁」。スチルは山場・回想カットとして短く使い、細かな感情変化は立ち絵で出す。

---

## 共通運用ルール

- ヒロインは星瓶堂の従業員ではなく、客・協力者・訪問者。
- 禁則語：店番 / 働く / 雇う / 再建。
- 10ターンは暦上の10日間ではなく、10回の営業。
- ナーディル表示名は「ナーディル」。内部IDは `nader`。
- ダリヤ表示名は「ダリヤ」。内部IDは `dariya`。
- 通常ルートは真っ直ぐハッピーエンド可能。
- long_historyは通常ルートの続きではなく、別世界線IF。

# 4. 実装反映時の注意

## まず入れる範囲

- 既存の `hakima_5`, `hakima_10`, `mira_5`, `mira_10`, `dariya_5`, `dariya_10` の本文差し替え。
- 各 ending の本文強化。
- 既存の routeMode / long_history 差分がある場合は、5イベント優先で差し替え。
- 10イベントの long_history は、実装が未対応なら normal 本文にフォールバック可。

## 画像運用

- スチルは会話中の表情差分として多用しない。
- 山場・回想・導入カットとして短く差し込む。
- 細かい感情変化は立ち絵差分で表現する。

## 長さ調整

- 各ページは60〜80字前後を目安。
- プレイテンポが重い場合、各イベントは2〜3ページまで圧縮可。
- Good Endingは4ページ程度、Normal/Badは2ページ程度で十分。
