1. 表情キー（Expression Taxonomy）

本編シナリオで使用可能な表情キーのみが有効です。

  • normal: 標準
  • joy: 喜び/笑顔
  • fun: 楽しみ/皮肉
  • sorrow: 悲しみ/困惑
  • cry: 泣き
  • anger: 怒り/ツン
  • surprise: 驚き/動揺
  • blush: 照れ/赤面

※ ギャラリー/素材専用（本編禁止）: student, social, maid

2. デイリートークの構造

DailyTalk は以下の4フェーズで構成されます。1と4はシステム側で自動挿入されます。

  1. Monologue (独り言): ナーディルの内心。店・天気・素材・営業前の気配を示す。
  2. Greeting (挨拶): ヒロイン来訪時の短い挨拶。出勤・常駐に見えないようにする。
  3. DailyTalk (本編): 本レポートに記載されているメイン会話。
  4. Farewell (別れ): ヒロイン退出時、または会話を切り上げる一言。

3. 視覚的制約とIFルート

  • 立ち絵表示: 常に一人まで（中央固定）。ヒロインがいる間、ナーディルは表示されません。
  • Route Mode (IF): long_history ルートは、過去から関係が続いていた別世界線IFです。
  • 禁則事項: 借金再建、店番、働く、雇う、スタッフ、店員など、旧設定や従業員感のある表現は禁止です。
  • キャラクター設定: ヒロインは星瓶堂の従業員ではなく、客・協力者・訪問者として関わります。
