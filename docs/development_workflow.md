# Development Workflow

Made in Maghribal の効率的な開発と、AIエージェントの負荷・クレジット消費を最適化するための運用ルールを定義します。

## 1. 役割分担 (Role Distribution)

各エージェントの特性に合わせて役割を分担します。

### Gemini / AG (Antigravity)
*   **用途**: ブラウザを用いた画面確認、複雑なE2Eテストの実行、環境状態（Serena）の物理的な確認。
*   **得意タスク**: 
    - Serena状態確認・アクティベート。
    - read-only snapshotの生成。
    - Playwrightを用いた実ブラウザでの挙動確認。
    - 限定的なE2Eテストの修正。
*   **禁止事項**: 長時間の修正ループ（複数回失敗した場合は停止して報告）。

### Codex
*   **用途**: コードの実装、リファクタリング、ドキュメントの更新。
*   **得意タスク**:
    - 単一ファイルのロジック修正。
    - テストコード（Unit/E2E）の単発修正・追加。
    - Helper関数の整理。
    - ドキュメント（docs/）の更新。
    - コミット前の差分（diff）整理。

### ChatGPT (Supervisor/Architect)
*   **用途**: 仕様の策定、タスクの分解、高レベルなレビュー。
*   **得意タスク**:
    - 実装仕様の判断。
    - 大規模タスクの小タスクへの分割。
    - Safety Stopの解除判断。
    - `git diff` のレビューと論理チェック。
    - AG/Codex 向けの簡潔な指示書の作成。
    - 小規模なパッチ（置換テキスト）の直接生成。

---

## 2. ChatGPT による小修正の分担

以下のタスクは、AG/Codexを介さず ChatGPT で直接パッチを作成し、ユーザーまたは軽量エージェントが適用することで効率化します。

*   **対象**: 
    - 軽微な文言修正（タイポ修正、ラベル変更）。
    - ドキュメント（.md）の追記・修正。
    - シンプルなイベント定義（affectionEvents.js 等）の追加。
    - E2E locator の単純な名称変更。
*   **運用**:
    - ユーザーは該当するコードブロックまたは `git diff` を貼る。
    - ChatGPT は「置換前」「置換後」のテキスト、または Codex 向けの最短の `replace_content` 指示を生成する。
    - 実行（テスト）が必要な重いタスクのみを AG / Gemini に回す。
